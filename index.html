What it is

01 / orientation

QEL is the quantum layer underneath a mesh network. Where a classical mesh asks which path does the packet take, QEL asks the harder question: if the links were quantum, where do the repeaters go, and what fidelity survives the trip?

It models the whole path. States are density matrices, so decoherence is modelled directly: depolarising, dephasing and amplitude-damping channels act on them, links attenuate with distance, memories relax on T1 and lose phase on T2, and weak entanglement has to be distilled back to something usable before a key can be extracted from it.

Placement decides whether a route works. A repeater chain is only as good as its worst link, and every swap costs fidelity, so the work is arithmetic about where the nodes go.

Entanglement cannot be copied. Each link has to be created, spent and replaced.
PropertyHow it is modelled
StateDensity matrices, with quantum information metrics
NoiseDepolarising, dephasing, amplitude damping
LinkDistance-dependent attenuation and hardware impairments

The stack

02 / three layers
Layer one

Core primitives

  • qubit density-matrix states, entropy and fidelity metrics
  • gate unitary gates, Pauli algebra, tensor products
  • measurement projective and POVM, with state collapse
  • noise depolarising, dephasing, amplitude damping
  • channel quantum and classical links, attenuation
  • physical fibre and hardware impairment models
  • stabilizer Clifford tableau for efficient QEC
  • scheduler asynchronous discrete-event core
  • ipc_node one process per node
Layer two

Protocols

  • bb84 QKD with an intercept-resend eavesdropper
  • e91 Ekert entanglement-based QKD
  • bell Bell preparation and CHSH inequality tests
  • teleportation state transfer over an EPR pair
  • superdense two classical bits through one qubit
  • swapping entanglement between nodes that never met
  • distillation BBPSSW and Deutsch purification
  • memory T1/T2 buffer dynamics
  • shor / steane 9-qubit and 7-qubit CSS codes
Layer three

Topology

  • graph nodes, optical links, fidelity models
  • routing fidelity-constrained entanglement routing
  • schedule time-aware distribution plans
  • visualize dependency-free ASCII output
  • ghostnet import a live mesh topology and route over it

Placement is the product here: given a graph, the topology layer answers where the repeaters go and what the surviving fidelity is along each route.

Protocols & codes

03 / what is implemented
QKD

BB84

Single-qubit key distribution with basis reconciliation, QBER estimation and an intercept-resend eavesdropper to detect.

QKD

E91

Ekert's entanglement-based key distribution, security argued from Bell inequality violation.

Verification

Bell states & CHSH

The four Bell states, Bell measurement, and CHSH inequality tests as an entanglement witness.

Transfer

Teleportation

An unknown state moved with a shared EPR pair and two classical bits — no matter transported.

Capacity

Superdense coding

Two classical bits carried by one qubit through Bell-state encoding.

Repeaters

Entanglement swapping

A middle node performs a Bell measurement to entangle two nodes that never interacted.

Purity

Distillation

BBPSSW and Deutsch protocols: N weakly entangled pairs in, one high-purity pair out.

Storage

Quantum memory

Buffer dynamics with T1 relaxation and T2 dephasing, so waiting costs fidelity.

QEC

Shor 9-qubit

Encoding, syndrome measurement and recovery for the original nine-qubit code.

QEC

Steane 7-qubit

The seven-qubit CSS code, correcting both bit and phase flips.

Simulation

Stabilizer formalism

Clifford tableau simulation under the Gottesman–Knill theorem, for circuits too large to track as vectors.

Physics

Physical layer

Fibre attenuation and hardware metrics turned into an impairment budget.

Theory

No-cloning

The reason any of this is secure: unknown quantum states cannot be copied, so eavesdropping leaves traces.

Bridge to the mesh

04 / classical discovery, quantum keys

Ghost-Net bridge. QEL imports a live topology export from Global Ghost Net and routes entanglement across exactly the nodes it describes. The same map that carries packets decides where quantum links could exist.

A route's end-to-end fidelity is the scheduled value once every swap and every memory decay on the path is accounted for. If that is too low for QKD to extract a key, the route is distilled — BBPSSW rounds over 256 pairs — until it is. Then a real BB84 exchange runs at the route's own noise level and produces key material.

Classical mesh discovery in · quantum key material out

# route entanglement over a live mesh export
py -m quantumnet ghost-net --topology mesh.json

# derive key material at an explicit fidelity
py -m quantumnet qkd-derive --fidelity 0.94 --out key.bin

# build and route a topology, ASCII out
py -m quantumnet topology --nodes 12 --route 0 11

RealSimulated
Quantum mechanics: states, gates, measurement collapse, noise channels, the stabilizer formalism, the error-correcting codes, distillation, and all fidelity arithmetic. Hardware and network: there are no photons, no fibre and no sockets. ipc_node uses real processes, but the links between them are modelled.
Scope: these are simulator results. They do not predict what physical hardware would achieve.
